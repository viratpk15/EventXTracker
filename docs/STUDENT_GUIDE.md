# EventXTracker — Student Portal User Manual
**Vidyavardhaka College of Engineering (VVCE), Mysuru**

## 1. Overview
The Student Portal provides students with a single, clear dashboard to discover campus events, participate individually or as teams, apply for volunteer duties, submit academic achievements, and receive real-time institutional notifications.

---

## 2. Key Workflows
1. **Discover Events:** Browse `/student/events` filtered by category, participation type, and date.
2. **Individual Registration:** Fill out event-specific custom questions. Identity fields (USN, name, department) are pre-filled automatically from verified profile records.
3. **Team Registration:**
   - Create a team with a project title and description.
   - Invite classmates by USN.
   - Invited peers receive immediate in-app notifications and can independently Accept or Decline.
   - Teams reach `COMPLETE` status once all required members accept.
4. **Academic Records Submission:**
   - Submit internships (company, domain, duration, stipend, technologies).
   - Submit external hackathons, symposiums, or paper presentations.
   - Submissions route automatically to the assigned Class Teacher for verification.
5. **Notifications:**
   - Access the notification center (`/notifications`) with real-time alerts on invitations, shortlist decisions, and review outcomes.
